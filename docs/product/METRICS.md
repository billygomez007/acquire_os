# Metrics Dictionary
Core: activation rate, time-to-first-approved-campaign, cost per qualified lead, qualified lead-to-meeting, meeting-to-customer, attributed revenue, retention, expansion revenue. Guardrails: ad budget overspend, message opt-out, unsupported claim rate, tenant leakage incidents, false positive lead qualification, spend API failures.
Every report must define denominator, lookback window, source, timezone, currency and level of confidence. Separate forecasting from observed results, and correlation from causal lift.
