# User Flows
Owner: sign up -> create org -> business brief -> connect ad account -> define KPI/budget -> AI draft -> approve -> launch -> inspect performance.
Growth Manager: review draft -> tune audience and creative -> submit for owner budget approval -> launch -> experiment -> monitor.
Sales Rep: new consented lead -> qualification summary -> contact -> appointment -> opportunity -> outcome.
Compliance Reviewer: evidence and consent -> accept/reject -> record reason.
Platform Support: controlled break-glass with time-bound access and audit.
